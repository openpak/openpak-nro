ams_mitm-1.12.1.kip
  Local modification:
  - allow SystemProgramId::Ssl in FsMitmService::ShouldMitmProgramId (tools/atmosphere-ssl.patch).
  - add bsd_mitm (stratosphere/ams_mitm/source/bsd_mitm, tools/atmosphere-ip-redirect.patch): a
    bsd:u mitm for the programs listed in /atmosphere/config/openpak/ip_redirects.txt (written by
    openpak-fetchd from the signed ceiling's ip_redirects). For those programs only, Connect (tcp
    rules) and SendTo (udp rules) to a listed IPv4 address:port go to the rule's target, and
    GetPeerName keeps reporting the dialled address; every other command, and every other
    program, is untouched.
  dns.mitm for firmware 23's new resolver is upstream since 1.12.1, so no dns patch is applied.

loader-1.12.1.kip and fusee-1.12.1.bin (OpenPak store trust)
  Local modifications, both in tools/atmosphere-store-trust.patch:
  - Loader (stratosphere/loader/source/ldr_meta.cpp): accept an invalid NPDM ACID signature
    only when the ACID's program id range lies within 0x01FE000000000000-0x01FEFFFFFFFFFFFF,
    the range OpenPak's store titles use. Every other program is verified as before.
  - fusee (fusee/program/source/fusee_stratosphere.cpp): one compiled-in patch to the stock
    FS KIP, applied only to an FS fusee identifies by hash: a tbz w0,#0 after the NCA header-1
    RSA verify becomes 1F 20 03 D5 (nop) at offset 0x26938 (FS 22.5.0, FAT32 and exFAT),
    0x279A8 (FS 23.0.0) or 0x279B8 (FS 23.0.0 exFAT).
  Built with tools/build-system-module.sh: Atmosphere 1.12.1 with tools/atmosphere-ssl.patch,
  tools/atmosphere-store-trust.patch and tools/atmosphere-ip-redirect.patch applied, git stamp pinned to -6b0c077-dirty, devkitARM r68
  and devkitA64 r30 (GCC 16.1), and libnx master at 146c3d1 (Atmosphere 1.12.x needs pgl's
  shell event API, which libnx 4.12.0 lacks). The stamp is pinned so a rebuild should give the
  same fusee.bin and KIPs differing only in their 20-byte GNU build IDs (which hash the absolute
  build path in the debug information); a second build has not been compared yet.
  sha256 ams_mitm-1.12.1.kip 258f90257ee7b4f33dff0f9ed05151120d2d9d864dfed1ab2e8a1b9760943a7c
  sha256 loader-1.12.1.kip   53c77a6b494379d889b0b604f69ab43437e169a013c4d84d8961ffbd014d24a3
  sha256 fusee-1.12.1.bin    b2931945873aa663edaa60970592aeaa717eba863cce220f2d46bf33bfe36b76
  fusee.bin is used with the MTC overlays already in the official package3 (the same as 1.11.2's);
  a build from these sources produces the same overlays, and the build script checks that.
